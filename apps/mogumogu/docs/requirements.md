# 離乳食・補完食 栄養可視化アプリ 要件定義書

2026年11月12日

> 実装状況と一次ソースとの差異は末尾「実装メモ」を参照。

## 1. 概要と背景

本アプリは、離乳食・育児用ミルク・母乳を合算した1日の栄養摂取量を推定し、月齢と性別に応じた「日本人の食事摂取基準（2025年版）」と比べて、栄養素ごとの過不足と成長曲線上の位置を見える化する個人用アプリである。

既存アプリではこの目的を満たせない。

| アプリ | できること | 足りない点 |
|---|---|---|
| カロミル（大人向け食事管理） | 食品DBから栄養素を自動計算 | 目標値が利用者自身の目標体重・体脂肪から決まる設計で、乳児の基準を持たない |
| ステップ離乳食 | 食材の記録、初めての食材チェック | 「栄養バランス」は記録した食材をエネルギー源・たんぱく質源・ビタミン/ミネラル源・その他に分けた件数比率だけで、鉄などの量（mg・μg）は出ない |

混合栄養では、供給側の前提を正しく持つことが本質になる。書籍の図「母乳から得られる栄養と必要量のギャップ（中期）」は完全母乳を前提に、鉄の必要量4.5mgのうち母乳から0.3mg、ギャップ4.2mgとしている（母乳エネルギー483kcalから逆算すると約740ml/日の想定）。一方、育児用ミルクの鉄は100mlあたり0.78〜0.99mgで、母乳0.04mgの約20倍ある。乳量の合計が同じでミルクが約250ml/日なら、鉄のギャップは約2mgまで縮む。

このため本アプリは、母乳（推定）・ミルク（実測）・離乳食（実測）を栄養素ごとに合算し、残りのギャップを示す。

| ID | ゴール |
|---|---|
| G1 | 栄養素ごとの摂取量を供給源（母乳・ミルク・離乳食）別に積み上げ、基準値とのギャップを数値で示す |
| G2 | 鉄・亜鉛・ビタミンD・カルシウムを重点監視項目として常に表示し、主要栄養素と全ビタミン・ミネラルも確認できる |
| G3 | 食材をg・ml・小さじ・大さじ・ユーザー定義単位で入力し、日本食品標準成分表の値で自動計算する |
| G4 | 体重・身長を記録し、乳幼児身体発育曲線上の位置と推移を確認できる |
| G5 | 判定はすべて「目安」として示し、診断的な表現を使わない |

## 2. 想定ユーザーと利用シーン

主な利用者は保護者1名で、キッチンスケールでg単位の計量ができる。

| 項目 | 内容 |
|---|---|
| 子ども | 女児、2026年4月2日生まれ（2026年11月時点で生後7か月） |
| 離乳の段階 | 離乳中期、1日2回食 |
| 栄養方法 | 混合栄養。育児用ミルク約250ml/日、残りは母乳と離乳食。母乳量は直接測れない |
| 食べ方の特徴 | 混ぜると食べないため、食材ごとに個別に盛り付けて与える。苦手な食材を切り分けたい |

| シーン | 頻度 | アプリでやること |
|---|---|---|
| 離乳食を与えた直後 | 1日2回 | 食材ごとに提供量と食べた量（または残量）を記録する |
| ミルクを飲ませた後 | 1日数回 | 銘柄とmlを記録する（飲み残しは差し引く） |
| 授乳のとき | 1日数回 | 回数だけ記録する。1日の母乳量は推定値を使う |
| 週末の振り返り | 週1回 | 7日平均の充足状況を見て、翌週の献立（特に鉄の補い方）を決める |
| 計測・健診のとき | 月1回程度 | 体重・身長を入力し、成長曲線を確認する |

## 4. 画面構成

5つのフッタータブ（記録・食材・栄養分析・成長・設定）で構成し、中心は栄養分析タブとする。記録タブで入れた内容を栄養分析タブで合算し、エネルギーの過不足は分析タブの注記から成長タブに移って確かめる。

## 6. 計算仕様

### 6.1 1日摂取量

I_n = Σ_i w_i · c_{i,n}/100 + Σ_j v_j · f_{j,n}/100 + V_bm · b_n

w=食べた重量(g)、c=可食部100gあたり、v=飲んだ量(ml)、f=100mlあたり、V_bm=母乳推定量(L)、b=母乳中濃度(/L)。容量単位は容量×係数(g/ml)。液体の既定係数は1.0。ユーザー定義単位は「1単位＝○g」。

### 6.2 基準値の選び方
1. 月齢＝基準日−生年月日（満月数）
2. 年齢区分の境界は栄養素ごとにデータで持つ
3. 推奨量を優先し、なければ目安量。エネルギーは推定エネルギー必要量、%E項目はエネルギー比で比べる
4. 耐容上限量は別に持つ。画面では「推奨量比」「目安量比」と書き分ける

### 6.3 判定
100%以上＝基準に届いている／70〜99%＝あと少し／70%未満＝届いていない／耐容上限量以上＝上限を超えている（警告色）。閾値は設定で変更可。色だけに頼らず文言とアイコンでも区別。

### 6.4 欠測
数値＝測定値／(数値)＝推定値（推定フラグ）／Tr・(Tr)＝0（微量フラグ）／(0)＝0／-＝欠測／空欄＝欠測。欠測を含む日は下限値とし、欠測食材の重量（例：鉄の欠測 12g/85g）を出す。母乳中濃度が定まっていない栄養素は母乳の寄与を欠測にする。

### 6.5 期間集計
日別合計の平均。記録が1件もない日は既定で除外。移動平均は7日。

### 6.6 注記
鉄は供給源によって吸収率が違う。含有量ベースで吸収率の補正はしない旨を表示。

## 実装メモ（一次ソースとの照合結果）

- **T-02**：食事摂取基準（2025年版）乳児 表3（p.375）の女児6〜8か月は、エネルギー600kcal・たんぱく質15g・鉄4.5mg（推奨量）・亜鉛2.0mg・ビタミンD5.0μg。書籍の図と一致。
- **ビタミンA**：乳児の目安量・耐容上限量は「プロビタミンAカロテノイドを含まない」（表3脚注1）。このため成分表のレチノール活性当量ではなく**レチノール列**で比較する（要件6.1の「μgRAE」から変更。一次ソースを正とした）。
- **母乳のビタミンD**：2025年版の母乳中濃度表（表1）は「—」。要件7章のとおり成分表 13051 人乳（0.3μg/100g）を比重1.017で換算して使う（約3.05μg/L）。
- **母乳中濃度**：表1は多くの栄養素で0〜5か月の値のみ。6か月以降も同じ濃度を使う（`breastmilk.csv` の flag=age05）。ビタミンEは「3.5〜4.0mg/L」の下限3.5を使用。ヨウ素の189μg/Lは括弧付き（目安量算定に未使用）の値で推定扱い。
- **母乳推定量の既定値**：DRIの算定に用いた哺乳量（0〜5か月780ml、6〜8か月600ml、9〜11か月450ml）を「母乳のみ」の既定に使う。
- **1歳以降の基準値**：未取り込み（TODO：表4〜を転記）。
- **発育曲線**：月齢区間（例：「6〜7月未満」）の値は区間の中央の月齢にプロット。
- **成長の相談の目安の閾値**：要件で参照される「12章」が手元の要件定義書にないため、3パーセンタイル未満・97パーセンタイル超・主要7本の曲線を2本以上またぐ（直前の記録または最初の記録との比較）を既定とし、設定で変えられるようにした。
